**Icon** — a Lucide glyph by name. The page must load Lucide (`<script src="https://unpkg.com/lucide@latest"></script>`).

```jsx
<Icon name="tv" size={28} />
<Icon name="heart" color="var(--accent)" />
```
Line icons, 2px stroke. Common names: `home, tv, radio, film, search, settings, heart, star, play, pause, signal, sparkles, chevron-right, columns-2, picture-in-picture-2`.
