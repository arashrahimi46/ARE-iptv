**IconButton** — square control for a single Lucide glyph. Player transport, nav, toolbars.

```jsx
<IconButton label="Play/Pause" variant="glass" size="lg"><PauseIcon/></IconButton>
<IconButton label="Favorite" active><HeartIcon/></IconButton>
```

Variants: `solid`, `glass` (blurred, for HUD over video), `ghost`. `active` paints it accent.
