**SidebarNav** — the left rail nav. Collapsed to icons, expands to labels on focus/hover. Needs Lucide (uses `Icon`).

```jsx
<SidebarNav active="home" items={[
  { id:"home", label:"Home", icon:"home" },
  { id:"live", label:"Live TV", icon:"tv" },
  { id:"movies", label:"Movies", icon:"film" },
  { id:"guide", label:"Guide", icon:"layout-grid" },
  { id:"search", label:"Search", icon:"search" },
  { id:"settings", label:"Settings", icon:"settings" },
]} />
```
