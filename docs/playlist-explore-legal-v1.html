01

Rename a playlist

New

Today the picker only offers destructive action: hold OK and the playlist is gone. The same gesture now opens a menu, so hold-to-delete becomes hold-to-choose — which also makes deletion harder to trigger by accident.

Nothing else moves

Channels, favourites and continue-watching are keyed by sourceId, not by name. A rename is a single-column update with no re-import and no cache invalidation.

Delete keeps its confirmation

Choosing Delete from the menu still shows the existing confirm step. The menu adds a choice, it does not remove a safeguard.

02

Explore free IPTV

New screen

Adding a playlist today means having a URL already. Most people do not. Explore offers around twenty vetted, publicly listed free playlists — pick one, name it, and it imports exactly like a playlist you pasted yourself.

How it stays fresh with no backend

Our list is only names and URLs — it changes rarely. The channels behind each URL are maintained continuously by iptv-org, so a bundled manifest still serves live content. The loader reads assets/explore.json through a single source constant, so pointing it at a hosted URL later is a one-line change.

The honest cost of bundling

If an entry's URL dies, it stays broken until the next app release. Mitigation: the import already reports failure, and the failure message should name Explore so the user knows the playlist — not their TV — is the problem.

Vetting bar for an entry

Free-to-air or public-domain only, publicly listed by a known community index, no paywalled or scrambled content, and it must resolve at the time of curation. Anything ambiguous does not go in the list.

03

Privacy & Terms

Accuracy gap

The current text says the app “does not collect or transmit”. The app ships Sentry crash reporting with no opt-out, Firebase analytics on by default, and calls OpenSubtitles, OMDb and Google Forms. The problem is not that the policy is short — it is that it is not true. Fixing the text without fixing the opt-out only makes the inaccuracy formal.

Ship the toggle in the same release as the text

A policy that promises an opt-out which does not exist is worse than the current placeholder. SentryAndroid.init must read the persisted preference before the text goes live.

Versioned acceptance

hasAcceptedTerms: Boolean becomes acceptedTermsVersion: Int. Existing users are re-prompted once with a “We have updated our terms” note. Every future update reuses the mechanism.

Translation policy in practice

Section titles, the short summary, buttons and the Settings rows go into all 21 locales. The clause bodies stay English with an “English version governs” line. A Turkish user never sees a broken screen, and you are never bound by a translation you cannot read.

Still blocking Play submission

Play requires a publicly reachable privacy policy URL. Bundling satisfies users but not the Console. The document is being written in Markdown precisely so it can be published later without a rewrite.

Build order

Sequenced so each phase is independently shippable and the riskiest item is not last.

Phase 1

Rename

  • Long-press menu in the picker
  • Rename dialog + ViewModel update
  • 3 new strings × 22 locales

Self-contained, no schema change. Ships alone.

Phase 2

Telemetry & legal

  • Crash-report toggle wired into Sentry init
  • Versioned acceptance + re-prompt
  • Full policy text, scroll modal, About rows

Highest exposure, so it goes before Explore — which adds exposure.

Phase 3

Explore

  • Migration 11→12, origin column
  • Bundled manifest + loader
  • Explore screen, name dialog, 10-playlist cap

Lands after the takedown process exists to back it.

Open

What still needs an answer

  • Legal identity. The document needs a real name, country and contact address before it can ship. Currently placeholdered.
  • Takedown contact. The Report a content issue row needs a destination — reusing the existing Google Form is the cheap option, but it appears in the policy as the official channel.
  • The curated twenty. The entry list itself has not been chosen or vetted.
  • Public hosting. Deferred, not solved. It returns the moment Play submission does.
