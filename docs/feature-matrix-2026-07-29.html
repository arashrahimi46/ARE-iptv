Verdict

ARE IPTV is no longer chasing parity — a full code audit shows nearly every "table stakes" gap from the last review cycle (catch-up, timeshift, recording, Stalker Portal) has quietly shipped, several undocumented. The app now leads the field on source breadth, subtitles, localization and theming depth. The real opportunity is no longer catching up — it's reliability & personalization moats (auto-fallback, playlist grooming, cloud settings sync) that no competitor in the set has shipped at all.

LEAD Where ARE already wins outright

Online subtitle fetching (OpenSubtitles, real API) · 24-language localization incl. RTL · all three source types (M3U + Xtream + Stalker) in one app · 8-preset accent system independently themed per light/dark mode · Home rail personalization engine ("Because you like X") · fully free, no ads, no paywall · tee-based DVR with FAT32 auto-split & crash recovery · multi-view grid.

GAP Where competitors still lead

No native Chromecast/casting · no EPG reminders/notifications · no true OS Picture-in-Picture (current "PiP" is an in-app mini-player, mislabeled) · no user profiles / kids mode · no backup-restore or cloud settings sync (GSE's #1 cited churn reason — real whitespace) · no EPG-program search · no voice control.

Theming — designed to be the best light theme in the category

Most IPTV apps treat light mode as an afterthought (inverted dark palette, poor contrast, glass effects that disappear on white). ARE IPTV's light theme is a fully independent token set, not an inversion — every glass surface gets its own alpha/tint tuning so it still reads as translucent on a bright page, and light mode gets its own accent shade ramp (600-weight vs dark's 500-weight) for AA contrast.

8 accent presets — independently themed per mode

Each of the 8 accent presets resolves to a different shade weight in light vs. dark (600 vs 500) so it always meets contrast, and a user can pick different accents per theme mode — e.g. Violet at night, Teal by day. No competitor in the benchmark set offers per-mode independent accent selection.

Light glass needs a visible borderDefault edge against near-white surfaces or the sidebar disappears — already handled per theme docs, verify on the new HUD/tab surfaces added since the last perf pass.

Ambient mesh contrast

The ambient backdrop mesh bake is tuned for dark; confirm the light-mode mesh doesn't wash out under bright content thumbnails (tileWashAlpha is already lower at 0.16 for light — validate on 4K HDR movie posters specifically).
